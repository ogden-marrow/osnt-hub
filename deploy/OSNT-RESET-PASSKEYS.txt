# OSNT: reset sign-in (passkeys)
#
# Use this if you lost your passkey. With the SD card in your computer:
#   1. On the line below this text, type a one-time code of at least 12 characters (letters and digits are fine).
#      Lines that start with # are ignored.
#   2. Save, eject the card, put it back in the Pi and power it on.
#   3. Within 30 minutes open  https://osnt-pi.local/setup  and enter that code to register a new passkey.
#
# WARNING: this removes every passkey that is registered now. Anyone who can read this card can do the same,
# so keep the card safe.
